# 🍄 Super Mario Argentino (Clon en Java)

Recreación de mecánicas básicas de un juego de plataformas estilo Super Mario.

## 🎮 Descripción
Juego de plataformas 2D con desplazamiento lateral donde el personaje puede moverse, saltar y colisionar con el entorno.

## 🚀 Características
- Sistema de movimiento y salto con gravedad
- Detección de colisiones con el entorno
- Scroll lateral del escenario
- Estructura modular basada en entidades

## 🛠️ Tecnologías
- Java
- Programación Orientada a Objetos

## 👥 Autoría
Proyecto realizado de forma colaborativa.
